# 仪表盘流量

仪表盘显示已有流量汇总和最近 30 天的上传、下载趋势，两块内容各自加载。
读取失败会在对应区域显示错误和“重试”；已经成功的另一块保持可见。
尚未取得汇总时显示加载或错误，不显示为 `0 B`；成功返回的零流量才显示零。
历史请求失败与成功返回空历史有不同提示。

趋势图标明日期范围、UTC 日期和 IEC 字节单位（B、KiB、MiB 等）。上传与下载
有文字图例，上传另外使用纹理，避免仅凭颜色区分。每日数值也以表格语义提供。
页面沿用现有中英文切换、浅色/深色主题与强调色。窄屏可在图表内部横向滚动，
日期和单位保持可读，页面本身不横向溢出。
辅助数据表不会在页面底部撑出额外空白。

流量聚合和无记录日期的补零仍由服务端负责；这里仅呈现现有上传、下载数据。
有关数据来源、保留和查询规则，见
[M10 可观测性计划](../plan/milestones/M10-observability-and-audit.md)。

桌面与手机 Chromium 用例验证独立加载、失败重试、零值/空值、日期单位、语言
与主题表现。图表用受控响应验证页面状态，不代替服务端聚合测试；文档语义和
键盘检查也不等于真实读屏软件兼容性或 WCAG 认证。确切用例与边界见
[并发功能验收矩阵](../acceptance/functional-matrix.md)。
