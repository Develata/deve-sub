# 节点整理与管理操作

本轮行为归属 M4 节点池、M5 模板、M6 订阅及 M7 链路与测速的现有边界。
节点管理页提供标签显示、协议/标签/地区/状态筛选和筛选结果选择。
筛选作用于当前已加载节点；超过首批 10,000 个节点时需继续加载，计数明确
显示匹配数与已加载数。表格使用虚拟行；窄屏在表格内部横向滚动。

## 标签

标签就是用户手动制定的分类。节点列表上方直接显示“全部节点”“未分类”和
每一个自定义分类，带色标和节点数；新建但尚未分配节点的分类也显示为 0。
点击分类查看所属节点，可继续叠加名称、协议、地区和状态筛选。分类计数统计
已加载节点、不随其他筛选改变；一个节点有多个标签时会计入多个分类。
切换分类会清除节点勾选并回到列表顶部，防止批量操作误及上一分类。
分类改名后保留当前选中状态，移除最后一个节点仍保留空分类；删除当前分类
后回到全部节点。刷新后从服务端重新加载分类及关联。分类加载失败时显示
重试入口，保留已有分类，不影响查看节点。

刷新成功会取消已移出当前分类或已不在加载列表中的勾选，避免批量操作带上
这些不可见节点。批量启停请求等待期间重新做出的选择不会被旧请求完成后清空。
节点刷新或加载下一页失败时，保留已有列表和勾选，可直接重试；成功后清除错误。

“管理标签”支持创建、重命名、选择色标和确认删除。重命名保留标签 ID 及
节点关联；删除解除所有关联。名称去掉首尾空白，按 Unicode 字符计长，
空白名称及非法颜色返回明确错误。

单节点标签编辑会先加载当前成员，保存可清空全部标签。多节点操作明确区分：

- **添加**：保留各节点其他标签，追加选择的标签，默认使用此模式。
- **移除**：只删除选择的标签，保留其他成员。
- **替换**：所有选中节点使用同一组标签；空集合表示清空。

每次批量操作在一个事务内完成。不存在的节点/标签使整批失败，不能留下部分
修改；重复标签 ID 视为一个成员，重复的节点赋值条目则拒绝，避免语义歧义。

## 订阅源表单

小屏源列表按条目纵向排列名称、地址、格式和状态，刷新、编辑、删除始终直接
显示在条目下方；桌面保留多列表格，无需在手机上横向滚动寻找操作。

添加、编辑和删除订阅源使用模态对话框，键盘焦点保持在当前操作内；关闭后回到
原入口。创建/编辑默认聚焦名称，按 Enter 保存，空的必填项会阻止提交。
编辑时 URL 留空表示保留已有地址，只有明确输入新地址才会替换；列表中的脱敏
地址只作提示，不会回填提交。更新间隔可以清空后重新输入，不会自动跳回默认值。窗口较矮时表单内部可滚动，
标签关联输入框，按钮和输入框保留触控尺寸与可见焦点。

保存期间保留当前对话框并暂时禁用编辑和取消，避免重复提交或旧请求关闭新表单；
请求失败或超时后恢复操作，保留填写内容并显示错误，可直接重试。空闲时可按
Escape 或取消关闭。源正在刷新时保存返回 409，保留草稿；刷新结束后可重试。
成功编辑会清除旧 HTTP 缓存验证值，下一次刷新重新获取正文并应用新配置。删除确认显示具体源名称，默认聚焦取消，继续保留节点退出
订阅的影响说明。

## 相关操作修复

- 人工覆盖编辑先读取现有完整覆盖；只改名称时保留 SNI、证书验证开关等字段。
  地区与启停筛选使用覆盖后的有效值。
- 模板编辑在当前版本加载成功前禁止保存，旧编辑请求不能覆盖后打开的模板。
  历史版本的回滚确认实际调用回滚命令。
- 新建订阅使用服务端支持的动态选择默认值；提交后可获取订阅内容。
- 源、模板、长期订阅列表可以继续加载后续分页；订阅表单加载完整模板选项。
- 多个源可同时刷新，各自保留忙碌状态。失败反馈不隐藏列表；失败处理只按
  当前 keep_on_fail 策略更新 enabled，保留同时发生的配置编辑。
- 手动导入与远程源包含同一节点时保留原 ID、标签和人工覆盖；远程源移除
  该节点不会撤销手动导入。先从源获取再手动导入、缺失后重新手动导入同样适用。
  旧版本未记录过的重复手动导入需再次导入，以明确建立独立来源；此前已被
  误标缺失的手动节点也需重新导入恢复，升级不会自动改写这些历史状态。
- 源改名或删除会同时使生成缓存过期；修复前的缓存按当前生成规则重新构建。
  当前仍满足撤销边界的有效缓存支持生成失败时的回退。
- 删除源后，仅由该源提供的节点退出分发，保留记录、标签和人工覆盖供诊断。
  其他源共有的节点和独立手动导入的节点继续可用。旧版删除源遗留的无来源
  远程节点在升级时同样退出分发；历史手动来源遗失的节点仍需重新导入。
  下次拉取订阅按当前节点重新生成；删除前的缓存不能通过失败回退或 304
  再次下发。筛选后完全无可用节点时明确返回不可用状态。
- 服务关闭时不再启动排队中的自动刷新；已启动任务在退出宽限内结束。
- 批量测速遇到不存在的节点时将其标为跳过，不伪报 DNS 失败。测速期间删除
  某个节点不会丢失其他节点的延迟历史；历史保存失败时任务显示失败并保留
  已采集的诊断结果。
- Web 请求超时后释放等待，过期响应不能覆盖较新的列表状态。
